# Zentao Daily Work Restructure Implementation Plan

目标：把个人与团队禅道日报迁移到独立 `F:\每日工作` 项目，并用可测试的 v2 渲染契约固定数据口径和展示结构。

实施项：

1. 个人范围与团队范围分离并由配置校验。
2. 个人 Bug 只进入“等待补充信息”或“人工需走查”一个分组。
3. 团队表保留未关闭候选；范围字段为空时标记部分完成，不归零。
4. 评论失败不得声称已添加；测试未进入断言阶段不得声称修复完成。
5. 两个 08:00 自动化迁移到独立项目并使用确定性渲染器。
6. 使用合成样例、配置、技能和自动化契约测试验收，不执行禅道或仓库副作用。
