# 测试 Bug 整理模板

只将用户消息、明确上下文和可读附件证明的内容整理到 Bug：

```text
标题：
环境/版本（仅已知）：
前置条件（仅已知）：
复现步骤：
实际结果：
期望结果：
证据说明：
```

没有证据的浏览器、状态码、账号、测试数据、日志内容和业务规则必须留空或向用户说明
缺失。明确创建后使用一次基础 `bug create`；创建失败或未知不通过第二次 create 或
comment 补偿。步骤段落使用真实换行拼接；多行内容优先写入受控 UTF-8 临时文件并传给
基础 `bug create --steps-file`。如果上游只有 JSON 序列化字符串，才传给基础
`--steps-json` 解码一次；不对普通文本无条件替换 `\\n`，用户明确输入的字面量必须保留。
